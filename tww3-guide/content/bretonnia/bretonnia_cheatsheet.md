# 브레토니아 전투 치트시트

전투 중 머리 하얘졌을 때 30초 안에 보는 페이지.

## 배치

- 중앙 = 농민/전열
- 좌우 끝 = 기사대
- 루앙/팔라딘 = 필요한 곳 지원
- 비행기병 = 포병·궁병·고립표적 대기

## 기본 사이클 차지

> **적 찍고 박음 → 몇 초 싸움 → 빈 땅 찍고 빠짐 → 거리 확보 → 다시 적 찍음**

랜스 진형:
- 우회 = OFF
- 돌격 직전 = ON
- 이탈 = OFF

## 돌격 우선순위

1. 후방
2. 측면
3. 움직이거나 교전 중인 적 정면
4. 준비된 창병 정면은 피함

## 양익 기병

첫 타부터 뒤까지 완벽히 돌 필요 없음.

> **측면 열렸으면 박고, 두 번째 타에 후방 노리기**

## 망치와 모루

- 모루 = 적을 붙잡음
- 망치 = 기사 측후방 돌격

팔라딘/루앙/성배수호자도 모루 역할 가능.

## 힐 체크

- 인원 거의 그대로 + HP 낮음 = 힐 맛있음
- 인원 많이 사라짐 = 이미 모델 손실 큼

## 피로 체크

계속 뛰고 싸운 기사대는 잠깐 쉬게 하기.

교대 사이클 차지가 좋은 이유:
- 한쪽이 쉬는 동안 다른 쪽이 박음

## 기병 두 카드가 한 적을 때

같은 방향으로 겹치지 말기.

- 좌/우
- 앞/뒤

로 나눠 박기.

## 공성

- 문에 기사 전부 몰아넣지 말기
- 1~2카드씩 진입
- 안쪽에서 공간 만든 뒤 재돌격
- 비행기병으로 후방 지원부대 제거

## 조작 기억

| 목적 | 조작 |
|---|---|
| 그룹 | Ctrl + 숫자 |
| 진형 통째 이동 | Alt + 좌클릭 드래그 |
| 우회 경로 | Shift 경로 |
| 돌격 | 적 유닛 우클릭 |
| 이탈 | 빈 땅 우클릭 |
| 카메라 | Insert |
| 머리 터짐 | 일시정지 |

## 절대 하지 말 것

- 창병 정면에 랜스 켜고 꼬라박기
- 기사 6카드를 한 적에게 한 방향으로 겹치기
- 돌격 후 그대로 세워두기
- 농민 칼싸움 구경하다 기병 잊기
- 힐을 인원수 확인 없이 쓰기

## 한 줄

**브레토니아는 ‘기사 수’보다 ‘돌격각과 재돌격 횟수’가 전투력을 만든다.**
