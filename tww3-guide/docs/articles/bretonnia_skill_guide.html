대화 기준 운용 메모 — 「브레토니아」 대화에서 추천한 성장 방향을 압축한 문서. 최신 패치 스킬트리 검증표나 레벨별 확정 빌드가 아니다. 정확한 스킬명·효과·선행 조건·해금 레벨·탈것 자동 획득 여부는 현재 게임 툴팁을 우선한다.

  • 기준 조합: 루앙 본대 + 플로렌스(천상 시녀) + 빈/소수 병력 생명 예언자 지원군.
  • 화살표는 투자 우선순위다. 선행 포인트가 필요하면 먼저 충족하며, 표시 순서대로 매 레벨 즉시 찍을 수 있다는 뜻은 아니다.
  • 탈것은 해금 시 탑승을 확인한다. 아래 순서에 있다고 반드시 스킬포인트를 쓰는 항목이라는 뜻은 아니다.
  • 역할·모집 특성·조합 상세는 기존 sources/bretonnia_lords_heroes.md 참고. 여기서는 “그래서 다음 포인트 어디 찍음?”만 다룬다.

1. 루앙 레옹쿠르#

구간 투자 우선순위
초반 행군자 → 고무적인 존재 → 글로르피니알의 후예. 이동과 주력 지상기병 강화부터
중반 왕의 군단 → 귀족 혈통 → 귀감 → 만인의 존경을 받는 자. 고유줄 해금에 맞춰 투자; 배퀴스는 해금 시 탑승 확인
후반 실제 기사 구성에 맞춰 영지의 수호자 / 기사도의 규범 → 본체 전투줄. 본체는 근접공격·방어 → 체력 → 무기피해 → 치명적인 맹습 방향
  • 핵심 스킬: 글로르피니알의 후예(Glorfinial's Progeny), 왕의 군단, 귀족 혈통. 이후 귀감과 기사 구성에 맞는 빨간줄.
  • 빨간줄 분기: 대화에서는 왕국기사·수행기사 중심이면 영지의 수호자(Protectors of the Realm), 성배·왕실 기사 중심이면 기사도의 규범(Chivalric Code)을 추천했다. 적용 병종과 부대 랭크 조건은 툴팁 확인.
  • 후순위: 농민 강화, 명백한 메시지, 왕실 인장 등 내정·모집 편의. 단, 왕실 비행기병을 본격 모집할 때는 왕실 인장의 우선순위를 재검토. 사자의 방패 관련 강화는 본체 생존 보강 때 검토.
  • 탈것: 대화에서 제시한 경로는 마갑 군마 → 왕실 페가서스 → 배퀴스. 배퀴스는 위 투자 순서를 끝낼 때까지 기다리는 항목이 아니다.
  • 서약/Troth: 대화에서는 루앙이 기사 서약을 모두 완료한 상태로 시작한다고 설명했다. 현재 캠페인 화면에서 확인하며, 이 상태를 새 일반 군주에게 그대로 대입하지 않는다.
  • 대화 기준 운용 메모: 원래 제안은 행군자 1 → 고무적인 존재 1 → 글로르피니알의 후예 3포인트. 포인트 수와 고유 스킬의 충원·유지비·기사도 수치는 패치 의존이므로 확정값으로 사용하지 않는다. 쿠론의 검 같은 장비 능력과 기본 회복 능력은 투자 스킬과 구분한다.
  • 한 줄 요약: 기사단 밥값부터 올리고, 배퀴스 탄 다음 왕 본체를 존나 센 보스몹으로 만든다.

2. 플로렌스 두보아 — 천상학파 시녀#

구간 투자 우선순위
초반 조화의 집결 → 자정 바람의 저주 집중. 바람 폭발은 보조로 최소 투자
중반 회피 → 마법 효율·시전자 강화 → 카산도라의 혜성 → 비전 전도체. 선행 조건에 맞춰 개방
후반 핵심 주문 강화 마무리 → 우라논의 벼락 → 연쇄 번개 → 필요한 캠페인·생존 보조
  • 핵심 스킬: 조화의 집결(Harmonic Convergence), 자정 바람의 저주(Curse of the Midnight Wind), 카산도라의 혜성(Comet of Casandora), 비전 전도체(Arcane Conduit).
  • 찍는 이유: 조화의 집결은 루앙·핵심 기사 지원, 자정 바람의 저주는 기사 교전·이탈 지원, 혜성은 적 밀집 구역 공격용이라는 대화의 역할 분담.
  • 후순위: 연쇄 번개, 남는 공격 주문, 직접 근접전 강화, 군단 밖 영웅 행동 투자. 휘몰아치는 하늘(Roiling Skies)은 패시브의 존재와 포인트 투자 여부를 구분하고, 이것만 보고 핵심 주문을 늦추지 않는다.
  • 탈것: 대화에서는 유니콘을 최종 기동 수단으로 추천했다. 해금하면 탑승 확인. 목적은 마법 위치 선정·기병 추종·탈출이다.
  • 서약/Troth: 플로렌스 개인의 Troth 단계와 보상은 대화에서 구체적으로 확정하지 않았다. 현재 시녀 화면에 해당 시스템이 있으면 조건 선택·진행을 확인한다. 영웅의 맹세가 군단장의 기사 유지비 조건을 대신한다고 해석하지 않는다.
  • 대화 기준 운용 메모: 바람 폭발 ‘1포인트 정도’는 당시 보조 투자 제안. 주문 비용·능력치 증감·지속시간은 재수록하지 않았다. ‘마법 저장량’이라는 당시 표현도 현재 스킬 효과를 확인해서 적용한다.
  • 한 줄 요약: 루앙 버프 → 적 디버프 → 뭉치면 혜성. 마법사를 칼싸움에 넣으면 씨발 인사사고다.

3. 생명학파 예언자 — 추가 지원 군주#

구간 투자 우선순위
초반 대지의 피 → 재생 개방·강화. 접근 가능한 회복 주문과 선행 조건부터
중반 회피 → 비전 전도체 등 마법 효율 → 회복 주문 강화 마무리. 왕실 페가서스 해금 시 탑승 확인
후반 돌가죽·가시 방패 → 지하 거주자. 독립 군단장이 되면 자기 기사 구성에 맞는 빨간줄을 앞당김
  • 핵심 스킬: 대지의 피(Earth Blood), 재생(Regrowth), 비전 전도체. 기본 원칙은 회복 > 마법 효율 > 버프·공격마법.
  • 회복 분담: 대지의 피는 모인 아군의 회복, 재생은 루앙·팔라딘·비싼 기사 등 중요한 대상의 회복에 쓰는 방향. ‘살린다’는 표현은 생존 지원의 뜻이며, 죽은 개체를 부활시킨다는 뜻으로 읽지 않는다.
  • 후순위: 직접 근접전 강화, 숲의 각성 등 남는 공격 주문. 플로렌스가 천상 공격마법을 맡는 현재 조합에서는 지하 거주자(The Dwellers Below)도 회복보다 뒤.
  • 빨간줄 분기: 빈/소수 병력 지원군이면 투자 효율이 낮아 미룬다. 자기 군단에 기사를 받아 독립하는 시점에 실제 병종에 맞춰 투자한다. 지원군의 군단 강화가 루앙 본대에도 적용된다고 가정하지 않는다.
  • 탈것: 대화에서 제시한 경로는 마갑 군마 → 왕실 페가서스. 회복 배달과 탈출용으로 운용.
  • 서약/Troth: 모집 직후 Troth 조건 선택부터 확인. 선택한 조건의 완료 및 다음 단계 선택을 챙긴다. 독립시키거나 고급 기사를 넘기기 전 해당 군주에게 적용되는 유지비 조건을 확인한다.
  • 대화 기준 운용 메모: 재생·회피·비전 전도체의 실제 접근 순서는 선행 조건에 따라 달라질 수 있다. ‘기사 몇 카드부터 독립’ 같은 고정 숫자는 기준으로 삼지 않고 군단 구성·경제·Troth 상태로 판단한다.
  • 한 줄 요약: 루앙이 적을 패면 얘는 루앙을 고친다. 왕의 사용시간을 존나 늘리는 출장 병원.

4. 보조 메모 — 일반 캐릭터의 스킬 방향#

대화 기준 운용 메모: 아래는 대화에서 정한 역할을 성장 단계로 압축한 보조 정리다. 일반 군주·팔라딘·야수 마법사의 개별 스킬명과 레벨별 클릭 순서는 당시 확정하지 않았다.

일반 브레토니아 군주#

  • 초반 → 중반 → 후반: 빈 지원 군주면 본체 전투·생존 → 탈것과 전투력 강화 → 독립할 때 자기 기사 빨간줄. 처음부터 병력을 지휘하면 이동·주력 병종 강화를 함께 고려.
  • 핵심: 적을 붙잡고 직접 싸울 본체 전투·생존 방향; 기사군단장이 되면 실제 병종 강화.
  • 후순위: 병력이 없는 동안 군단 빨간줄, 쓰지 않는 병종 강화. 루앙 고유 스킬을 일반 군주에게 복사하지 않는다.
  • 탈것: 대화상 군마 → 페가서스 → 히포그리프 방향. 현재 해금 조건 확인.
  • 서약/Troth: 기사 서약 선택 → 조건 수행 → 다음 단계 확인. 고급 기사 인수 전 군단장 서약 검사.
  • 한 줄 요약: 빈손일 땐 본인이 병력이고, 기사 받으면 군단장 빌드로 전환한다.

일반 예언자 공통 — 생명·천상·야수#

  • 초반 → 중반 → 후반: 학파의 주력 주문 → 시전자 효율·기동성 → 보조 주문 및 독립 군단의 기사 강화.
  • 핵심: 생명은 회복, 천상은 버프·디버프·광역 공격, 야수는 버프·소환·지원이라는 대화의 분담. 생명은 3절, 천상은 2절의 주문 우선순위를 참고하되 군주·영웅 트리 차이는 확인.
  • 후순위: 직접 근접전, 빈 군단의 빨간줄, 다른 마법사가 이미 충분히 담당하는 역할에 대한 중복 투자.
  • 탈것: 대화상 마갑 군마·왕실 페가서스 계열. 학파별 현재 목록 확인.
  • 서약/Troth: Troth 조건을 먼저 선택하고 단계별 진행을 확인. 야수의 구체적 주문 순서는 대화에서 미확정.
  • 한 줄 요약: 마법은 예언자가, 앞에서 처맞는 일은 팔라딘이 맡는다.

팔라딘#

  • 초반 → 중반 → 후반: 전선에서 버틸 생존·근접전 방향 → 기동성과 핵심 표적 교전 능력 → 남은 본체 강화·필요한 보조 능력.
  • 핵심: 적 군주·괴수 견제, 적을 붙잡아 기사 돌격각 만들기. 정확한 개별 스킬 우선순위는 대화에서 미확정.
  • 후순위: 군단 내 전투 역할과 무관한 영웅 행동 투자. 군주용 빨간줄 빌드를 그대로 적용하지 않는다.
  • 탈것: 대화에서는 페가서스 활용을 언급. 실제 탈것 이름·해금 조건은 화면 확인.
  • 서약/Troth: 기사 서약을 진행해 본체 보너스를 확보하는 방향. 대화에서 언급한 ‘완벽한 활력’ 등 최종 보상은 현재 툴팁 확인. 팔라딘의 서약을 군단장의 유지비 서약 대체재로 보지 않는다.
  • 한 줄 요약: 살아있는 말뚝. 얘가 버티는 동안 기사가 뒤통수를 박는다.

시녀 공통 — 생명·천상·야수#

  • 초반 → 중반 → 후반: 학파 핵심 주문 → 마법 효율·기동성 → 보조 주문·생존·필요한 캠페인 지원.
  • 핵심: 생명은 회복 우선, 천상은 플로렌스 순서 참고, 야수는 기병·캐릭터 지원 방향. 생명 예언자의 주문 원칙은 참고하되 군주 전용 스킬까지 복사하지 않는다.
  • 후순위: 직접 근접전, 현재 쓰지 않는 주문, 군단 배속 운용 중 외부 영웅 행동 투자. 야수의 세부 클릭 순서는 미확정.
  • 탈것: 천상 플로렌스는 대화상 유니콘. 다른 학파의 최종 탈것은 일괄 단정하지 않고 목록 확인.
  • 서약/Troth: 대화에서 시녀의 상세 조건·보상은 미확정. 현재 화면의 Troth 적용 여부와 진행 조건을 확인하며, 군단장의 유지비 조건과 구분.
  • 한 줄 요약: 일반 군주가 싸우는 동안 마법 지원. 몸으로 해결하려 들지 말자.

5. 레벨업 때 10초 확인#

  1. 빈 지원 군주인가, 병력을 가진 군단장인가? 빨간줄 우선순위를 가른다.
  2. 핵심 주문·고유 스킬 선행 조건이 열렸나? 이름만 보고 잠긴 곳까지 직행하려 하지 않는다.
  3. 탈것이 해금됐나? 탑승 상태를 확인한다.
  4. 서약/Troth를 선택했고 실제로 진행 중인가? ‘따라다니면 알아서 되겠지’ 하다 허송세월하지 않는다.
  5. 강화 대상이 자기 군단·자기 캐릭터에 맞나? 고급 빨간줄의 적용 병종·랭크 조건까지 확인.
