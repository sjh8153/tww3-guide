가장 중요한 원칙기본 사이클 차지이탈 방향랜스 진형여러 기병을 한꺼번에 들이박는 법그룹 지정진형 통째로 이동Shift 경로 지정그룹 추천농민 전열 운용두 기병이 한 적을 때릴 때비행기병 운용페가서스 계열왕실 히포그리프 기사패주병 추격카메라 감상일시정지손가락용 치트시트한 줄 정리

기준: 현재 대화에서 정리한 수동전투 조작 메모. 목표: 병종 설명보다 실제 마우스/단축키 운용법을 빠르게 다시 떠올리는 용도.

가장 중요한 원칙#

박을 땐 적을 찍고, 빠질 땐 땅을 찍는다.

  • 적 유닛 우클릭 = 공격/돌격 명령
  • 빈 땅 우클릭 = 이동/이탈 명령

적 뒤 공터를 찍는다고 지나가면서 자동 돌격 판정이 들어가는 게 아니다. 제대로 된 돌격을 넣으려면 적 부대를 직접 우클릭한다.

기본 사이클 차지#

  1. 측면/후방으로 이동
  2. 랜스 진형 ON
  3. 적 유닛 직접 우클릭
  4. 충돌 확인
  5. 몇 초 근접공격
  6. 랜스 OFF
  7. 가까운 바깥쪽 빈 땅 우클릭
  8. 거리 확보
  9. 방향 재정렬
  10. 다시 랜스 ON → 재돌격

초보 기준 감각:

박음 → 5~10초 팸 → 뺌 → 거리 벌림 → 다시 박음

단, 상대가 궁병/포병/패주병처럼 약하면 굳이 빼지 않고 그대로 죽여도 된다.

이탈 방향#

적 부대를 관통해서 반대편으로 빠지려 하지 않는다.

좋은 이탈:

  • 들어온 방향
  • 가장 가까운 측면 공터
  • 적 모델이 적은 쪽

나쁜 이탈:

  • 적 부대 한가운데를 뚫고 반대편으로 이동

이탈 명령을 한 번 줬는데 몇 모델이 붙잡히면 빈 땅 우클릭을 다시 반복한다.

랜스 진형#

랜스 진형은 사실상 돌격 모드라고 이해하면 쉽다.

추천:

  • 우회/일반 이동 = OFF
  • 돌격 직전 = ON
  • 충돌 후 이탈 = OFF

계속 켜두면 선회와 이탈이 답답해질 수 있다.

주의:

랜스 진형을 켰다고 준비된 창병 정면돌격이 좋은 판단으로 바뀌지는 않는다.

여러 기병을 한꺼번에 들이박는 법#

기병 여러 부대를 일렬로 세운 뒤 잠금 그룹을 사용한다.

그룹 지정#

  • 여러 유닛 선택
  • Ctrl + 숫자로 그룹 지정
  • 자물쇠를 잠가 현재 상대 위치관계를 유지

잠금 그룹 상태에서 적 전열에 공격 명령을 내리면 여러 유닛이 전부 한 적에게 뭉치기보다 각자 전방의 표적을 나눠 물기 쉬워진다.

주의:

  • AI 표적 배분이 완벽하지 않다.
  • 창병/할버드/괴수가 섞여 있으면 직접 표적 지정이 낫다.

진형 통째로 이동#

여러 유닛을 원하는 진형으로 배치한 뒤:

  • Alt + 좌클릭 드래그 = 현재 진형을 유지한 채 통째로 이동
  • Alt 드래그 중 Ctrl = 진형 회전

브레토니아는 기병 조작에 손을 써야 하므로 보병/궁병 진형을 일일이 다시 배치하지 않고 통째로 움직이는 게 중요하다.

Shift 경로 지정#

기병 우회에 유용.

  • 적 정면을 최단거리로 가로지르지 않게 한다.
  • 측면 바깥 → 후방 → 돌격 준비 위치 순으로 경로를 꺾어준다.

즉:

우회 경로는 Shift, 돌격은 적 직접 우클릭.

그룹 추천#

초보용:

  • 1번 = 왼쪽 기사대
  • 2번 = 오른쪽 기사대
  • 3번 = 농민 전열
  • 4번 = 궁병
  • 5번 = 루앙/영웅

핵심은 기병 6~8카드를 전부 개별로 조작하지 않는 것.

처음엔 좌우 2카드씩 정도만 직접 다루는 게 좋다.

농민 전열 운용#

농민 전열은 잠금 그룹으로 묶고 적 전열과 붙게 만든 뒤 손을 뗀다.

브레토니아 수동전투에서 플레이어의 시선 우선순위:

  1. 기병
  2. 루앙/팔라딘
  3. 마법
  4. 농민

농민 칼싸움 구경하는 동안 기사들이 창병한테 갈리고 있으면 손해다.

두 기병이 한 적을 때릴 때#

같은 방향에서 겹쳐 박지 않는 것이 좋다.

좋은 형태:

  • 한 부대는 왼쪽
  • 한 부대는 오른쪽
  • 또는 앞/뒤에서 동시에 압박

이유:

  • 기사끼리 길막 감소
  • 적 포위 효과 상승
  • 이탈도 쉬움

비행기병 운용#

비행기병의 장점은 정면전을 잘하는 게 아니라 정면전을 할 필요가 없다는 것.

페가서스 계열#

역할:

  • 포병 습격
  • 궁병 물기
  • 비행유닛/기병 요격
  • 고립된 적 지원부대 제거
  • 패주 직전 부대 마무리

운용:

날아감 → 약한/중요한 곳 착륙 → 짧게 싸움 → 이탈/재이륙 → 다른 곳 출동

즉 전장 벌쳐/응급출동팀.

왕실 히포그리프 기사#

  • 페가서스보다 지상 난전과 강한 표적 상대에 강함
  • 그래도 할버드 여러 부대 정면에 박아두고 잊는 식으로 쓰면 안 됨

패주병 추격#

전투 중반까지 기사 = 충격기병. 전투 후반 기사 = 살인청소차.

패주한 적을 끝까지 추격해 개체 수를 줄이면 캠페인에서 다음 턴 재전투 부담이 크게 줄어든다.

카메라 감상#

보고 싶은 부대 선택 → Insert

  • 부대 시점 추적 카메라
  • 기사 돌격 장면 감상에 좋음
  • K로 UI를 숨기면 시네마틱 감상 가능

주의:

30초 감상하고 나오면 반대쪽 전선이 사망해 있을 수 있다.

일시정지#

초보일수록 적극 활용한다.

  • 기병 표적 지정
  • 루앙 표적 지정
  • 궁병 점사
  • 마법 예약
  • 좌우 기사단 이탈 명령

실시간으로 20개 전부 조작하는 게 목적이 아니다. 정확한 명령을 내리는 게 목적이다.
