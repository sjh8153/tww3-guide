묘영 — 주력군 지휘 / 사격군단 + 생명마법도연 — 전투형 전설영웅 / 옥전사 지원 + 대형 사냥대상인장 — 대상단 생존 / 수익천문술사 — 현재는 3군단 광역마법 담당군단 배속형지도 요원형으로 별도 운용할 때연단술사 — 현재는 독립 암살 요원암살 요원형 — 현재 선택군단 배속형을 별도로 키울 때현재 추천 역할 분담

기준: 기존 「케세이」 대화의 최종 정정·압축 메모와 현재 군단 구성. 저장일: 2026-09-07. 게임 최신 패치를 새로 검증한 문서가 아니라, 대화에서 확정한 내용을 정리한 플레이 메모다.

묘영 — 주력군 지휘 / 사격군단 + 생명마법#

  1. 빨강줄에서 현재 가장 많이 쓰는 병종 강화: 초중반 옥전사·옥전사 석궁병 중심.
  2. 생명마법 핵심: 대지의 피 → 재생. 대지의 피가 이미 있으면 주력병종 강화부터 진행.
  3. 묘영 고유 스킬.
  4. 개인 전투력 / 용 변신 강화.

군단 강화 → 회복 확보 → 본체 강화. 회복으로 묘영·도연 등 비싼 단일 개체를 지원한다.

도연 — 전투형 전설영웅 / 옥전사 지원 + 대형 사냥#

  • 12랭크 전: 근접공격·근접방어 등 본체 강화. 9랭크 상양의 칼날과 발톱 추천.
  • 12랭크: 복수라는 원동력 최우선.
  • 이후: 옥전사 방어 강화(물리저항 +10%, 리더십 +8, 근접방어 +6) → 옥전사 유지비 -15% / 모집랭크 +1 → 고유 구간 4포인트 투자 → 철룡의 집행자.
  • 철룡의 집행자로 최종 선고 확보: 주변 적 근접방어 -24.
  • 이후 개인 전투라인 → 거상의 일격으로 대형 상대 강화.

정정 반영: 옥전사 고유 강화는 12랭크 이후다. 옥전사 계열 근접공격 +6·사거리 +15%는 도연의 기본 특성 효과이며, 따로 찍는 스킬이 아니다.

대상인장 — 대상단 생존 / 수익#

매복 위험 감소 → 화물 판매가치 증가 → 소모 피해 감소 등 생존 → 이동·지름길 관련 → 최대 화물량 증가 → 추가 적재량 → 남는 포인트만 전투.

  • 이동·최대 화물량 관련 상위 스킬은 대화 기준 약 10랭크부터 고려.
  • 이벤트로 병력 구성이 달라지므로 특정 병종 빨강줄에 과투자하지 않는다.
  • 정정 반영: 초반부터 화물 적재량을 최우선으로 찍으라는 이전 안내는 제외. 안전하게 도착해 수익을 회수하는 것이 목적이다.

천문술사 — 현재는 3군단 광역마법 담당#

군단 배속형#

  1. 천상학파 핵심 주문: 혜성 등 보병 상대 광역마법.
  2. 12랭크 시전자 강화: 천상학파 주문 재사용시간 감소·주문 강도 증가.
  3. 14랭크 전문화: 실제 군단 구성에 맞춰 선택.
    • 옥사자·흑옥사자·병마용 중심: 해당 유닛 강화.
    • 월조·천사자 중심: 해당 유닛 강화.
    • 일반 군단: 천문술사 주문 사거리·장갑 강화.

지도 요원형으로 별도 운용할 때#

영웅 행동 성공률 → 행동 비용 감소 → 이동 차단 강화 → 캠페인 이동·생존. 이동 차단 / 기술 훔치기 / 부상 담당.

연단술사 — 현재는 독립 암살 요원#

암살 요원형 — 현재 선택#

전문화·영웅 행동 성공률 → 암살 성공률 강화 → 행동 비용 감소 → 캠페인 이동·생존 → 남는 포인트로 마법.

  • 지도 행동: 암살 / 충원 방해 / 성벽 파괴.
  • 군단에 넣지 않고 독립 행동. 전투스킬보다 요원 능력을 우선한다.

군단 배속형을 별도로 키울 때#

금속학파 핵심마법 → 주문 재사용시간 감소 → 마법의 바람 최대량 증가 → 자기강화·회복 → 군단 지원(이동거리 / 무기피해 / 장갑 중 선택).

현재 추천 역할 분담#

구분 구성 역할
1군단 묘영 + 도연 주력군. 묘영은 군단 강화·회복, 도연은 옥전사 지원·대형 사냥
2군단 용혈수환관주 + 일반병력 군주가 마법을 담당하는 별도 군단
3군단 현령 + 천문술사 + 일반병력 현령은 지휘·군단 지원, 천문술사는 광역마법
지도 요원 암살 전문 연단술사 군단 밖에서 적 영웅 암살
대상단 대상인장 대상단 생존·이동·수익 확보
